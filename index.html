THE SIMPLE FORMULA

Small rules.

Choose your equipment, set the sequence length, and complete the routines in order whenever life gives you the time.

PROGRESSION

Own the range.
Then add weight.

Use one working weight for all three sets. Try to reach the session max on every set, but never let a later set exceed the reps completed on the set before it.

Set 16–10 reps
Set 26–Set 1 reps
Set 36–Set 2 reps

Example: 9 reps, then 7 reps means the next target is 6–7. Increase weight next session when all three sets reach 10.
